# ScreenMatch Version 1

Simple mobile-friendly phone screen/camera protector matcher.

## Edit database
Open `data.js`. Add models, aliases, and screen/camera matches. Levels: `exact`, `good`, `check`, `no`.

## Publish with GitHub Pages
1. Create a public repository.
2. Upload all files.
3. Settings → Pages.
4. Deploy from `main` branch, `/ (root)`.
5. Open the published site in Safari and choose Share → Add to Home Screen.
